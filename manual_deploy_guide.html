第一步

创建并初始化 D1 数据库

D1 是 Cloudflare 官方提供的无服务器 SQLite 数据库，用于存储用户、邮箱别名、收发的邮件与附件。

  1. 登录 Cloudflare 控制台；
  2. 在左侧菜单栏中点击：存储和数据库 (Storage & Databases) ➔ D1 SQL 数据库；
  3. 点击蓝色的 「创建数据库 (Create database)」 按钮；
  4. 数据库名称填写：cfmail_db，点击 创建；
  5. 创建完成后，点击刚刚创建好的 cfmail_db 进入详情页，切换到顶部的 「控制台 (Console)」 标签页；
  6. 在控制台输入框中粘贴下方的建表 SQL 语句，点击右下角的 「执行 (Execute)」 按钮：
初始化建表 SQL (schema.sql) 
-- 1. 用户表
CREATE TABLE IF NOT EXISTS users (
    id TEXT PRIMARY KEY,
    username TEXT UNIQUE NOT NULL,
    password_hash TEXT NOT NULL,
    salt TEXT NOT NULL,
    role TEXT NOT NULL DEFAULT 'user',
    is_active INTEGER NOT NULL DEFAULT 1,
    quota_bytes INTEGER NOT NULL DEFAULT 524288000,
    used_bytes INTEGER NOT NULL DEFAULT 0,
    created_at INTEGER NOT NULL,
    updated_at INTEGER NOT NULL
);

-- 2. 托管域名表
CREATE TABLE IF NOT EXISTS domains (
    id TEXT PRIMARY KEY,
    domain_name TEXT UNIQUE NOT NULL,
    is_active INTEGER NOT NULL DEFAULT 1,
    is_default INTEGER NOT NULL DEFAULT 0,
    description TEXT,
    created_at INTEGER NOT NULL
);

-- 3. 邮箱别名表
CREATE TABLE IF NOT EXISTS mailboxes (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    address TEXT UNIQUE NOT NULL,
    domain_id TEXT,
    name TEXT,
    is_primary INTEGER NOT NULL DEFAULT 0,
    is_active INTEGER NOT NULL DEFAULT 1,
    created_at INTEGER NOT NULL,
    FOREIGN KEY (user_id) REFERENCES users(id) ON DELETE CASCADE
);

-- 4. 邮件核心表
CREATE TABLE IF NOT EXISTS emails (
    id TEXT PRIMARY KEY,
    mailbox_id TEXT NOT NULL,
    user_id TEXT NOT NULL,
    message_id TEXT,
    direction TEXT NOT NULL,
    from_name TEXT,
    from_address TEXT NOT NULL,
    to_addresses TEXT NOT NULL,
    cc_addresses TEXT,
    bcc_addresses TEXT,
    reply_to TEXT,
    subject TEXT,
    snippet TEXT,
    body_text TEXT,
    body_html TEXT,
    raw_size INTEGER NOT NULL DEFAULT 0,
    is_read INTEGER NOT NULL DEFAULT 0,
    is_starred INTEGER NOT NULL DEFAULT 0,
    is_trash INTEGER NOT NULL DEFAULT 0,
    is_spam INTEGER NOT NULL DEFAULT 0,
    created_at INTEGER NOT NULL
);

-- 5. 邮件附件表
CREATE TABLE IF NOT EXISTS attachments (
    id TEXT PRIMARY KEY,
    email_id TEXT NOT NULL,
    filename TEXT NOT NULL,
    content_type TEXT NOT NULL,
    size INTEGER NOT NULL,
    storage_type TEXT NOT NULL DEFAULT 'd1_blob',
    storage_key TEXT,
    data_blob BLOB,
    created_at INTEGER NOT NULL
);

-- 6. 全局系统配置表
CREATE TABLE IF NOT EXISTS settings (
    key TEXT PRIMARY KEY,
    value TEXT NOT NULL,
    description TEXT,
    updated_at INTEGER NOT NULL
);

-- 7. 发信审计日志表
CREATE TABLE IF NOT EXISTS send_logs (
    id TEXT PRIMARY KEY,
    user_id TEXT NOT NULL,
    from_address TEXT NOT NULL,
    to_addresses TEXT NOT NULL,
    subject TEXT,
    channel TEXT NOT NULL,
    status TEXT NOT NULL,
    error_message TEXT,
    created_at INTEGER NOT NULL
);

第二步

创建 Worker 并绑定 D1 数据库

Worker 是整个系统的核心引擎，负责提供 HTTP 接口、托管前端静态网页以及接收 Email Routing 路由投递过来的邮件。

  1. 在 Cloudflare 左侧菜单点击：计算和无服务器 (Compute / Workers & Pages) ➔ 概述 (Overview)；
  2. 点击右上角蓝色的 「创建 (Create application)」 ➔ 选择 Worker；
  3. 服务名称填入：cfmail，点击 「部署 (Deploy)」；
  4. 创建成功后，点击进入这个名为 cfmail 的 Worker 主页；
  5. 点击顶部的 「设置 (Settings)」 标签页：
    • 找到 「绑定 (Bindings)」（或“变量与机密”）区域，点击 「添加绑定 (Add)」；
    • 选择 D1 数据库绑定；
    • 变量名称 (Variable name) 务必填：DB（必须大写）；
    • D1 数据库 下拉选择在第一步创建的：cfmail_db；
    • 点击 「保存并部署」！
⚠️ 关键提醒：变量名称必须一字不差填为大写的 DB，否则 Worker 代码将无法读取数据库。
第三步

在网页编辑器中粘贴部署代码

我们已为您将后端全部逻辑（包含 postal-mime MIME 邮件流式解析引擎、JWT 鉴权、RESTful API 以及 Webmail 前端页面）打包成了一个独立的单文件脚本。

  1. 在 cfmail 的 Worker 详情页右上角，点击 「编辑代码 (Edit code)」；
  2. 清空左侧代码编辑器中原有的默认代码；
  3. 打开项目根目录下的 worker.bundle.js 文件，全选并复制全部内容，粘贴到 Cloudflare 网页编辑器中；
  4. 点击右上角蓝色的 「保存并部署 (Save and deploy)」 按钮！
🎉 部署成功后，您就可以点击页面提供的 Worker 访问地址（如 https://cfmail.your-name.workers.dev），直接在浏览器中打开漂亮的 Webmail 界面了！
第四步

配置域名 Email Routing 收信规则

将外发至您自定义域名（如 00571.top）的邮件全部引流至我们的 Worker 中处理。

  1. 在 Cloudflare 左侧菜单点击 网站 (Websites) ➔ 点击您的域名：00571.top；
  2. 在域名的左侧菜单中找到 「电子邮件 (Email Routing)」：
    • 如果未开启，按照页面提示点击开启，Cloudflare 会引导一键添加 MX 解析记录与 SPF 防伪记录；
  3. 切换到 「路由规则 (Routing Rules)」 标签页：
    • 找到 全部捕获 (Catch-all) 规则卡片，点击右侧的 「编辑」；
    • 操作 (Action) 选择：发送到 Worker (Send to Worker)；
    • 目标 Worker 选择刚刚部署的：cfmail；
    • 点击 保存并启用！
至此，外部任何人向 admin@00571.top 或 任意前缀@00571.top 发送邮件，全都会 100% 自动实时写入您的收件箱！
第五步

首次注册管理员与配置发信 (Resend)

系统首位注册的用户会自动成为最高系统管理员。

  1. 打开您的 Worker 网址（如 https://cfmail.xzal520.workers.dev）；
  2. 点击 「新用户注册」，输入用户名与密码，邮箱后缀默认即为 @00571.top；
  3. 注册成功后直接登录，进入现代化邮件收发客户端界面；
  4. 点击顶部导航栏右上角的 「管理后台」 ➔ 切换到 「发信通道 & 设置」：
    • 免费注册 Resend 官网 并复制 API Key；
    • 粘贴进 Resend API Key 输入框并点击保存；
    • 在下方输入您的个人常用邮箱（如 QQ 或 163 邮箱），点击 「立即测试发信」，收到测试邮件即代表全链路彻底打通！
